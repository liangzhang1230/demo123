# 销售定薪器 · HR 版 —— 部署与运维说明(小白版)

四个文件的分工:

| 文件 | 是什么 | 放哪 |
|---|---|---|
| `hr-dingxinqi.html` | 卖给 HR 的产品(单文件,离线可用) | 服务器 nginx 静态目录,给买家一个网址 |
| `fama-server.js` | 发码接口+网页管理后台 | 服务器,pm2 守护运行 |
| `fama-offline.html` | 卖家离线发码器(**含密钥,严禁外传**) | 只放你自己电脑,双击使用 |
| `部署说明.md` | 本文件 | — |

---

## 一、上线前必改的三个值

1. `fama-server.js` 顶部 `ADMIN_TOKEN`:改成你自己的长随机串(管理后台口令);
2. (可选)三个文件里的产品密钥 `ACT_SECRET` / `secret`:当前已内置同一把随机密钥,可直接用;若要换,**三处必须同时改成同一个值**(hr-dingxinqi.html、fama-server.js、fama-offline.html),换密钥后旧激活码全部失效——只在首次上线前换,上线后别动;
3. `hr-dingxinqi.html` 顶部 `API_URL`:填你的接口地址(如 `http://服务器IP:8787`);留空则隐藏"自助领码"入口,纯人工发码模式。

## 二、部署步骤(腾讯云服务器)

```bash
# 1. 装 Node(已装可跳过;要求 ≥14)
node -v

# 2. 上传文件到服务器,比如 /srv/hrdx/
mkdir -p /srv/hrdx && cd /srv/hrdx
# (把 fama-server.js 传上来;hr-dingxinqi.html 放进你现有 nginx 静态目录)

# 3. 试运行
node fama-server.js
# 看到 [fama] 发码服务已启动 即成功,Ctrl+C 停掉,转 pm2

# 4. pm2 守护(第三层保险:进程崩溃自动拉起+开机自启)
npm install -g pm2
pm2 start fama-server.js --name fama
pm2 startup     # 按它输出的提示执行一遍
pm2 save

# 5. 腾讯云控制台 → 防火墙/安全组:放行 8787 端口(TCP)

# 6. 验证
curl http://127.0.0.1:8787/api/health
# 返回 {"ok":true,...} 即成功
```

浏览器打开 `http://服务器IP:8787/admin` 就是管理后台(输 ADMIN_TOKEN 进入)。

**备案下来之后**:把 HTML 和接口都挂到正式域名 443(nginx 反代 8787),并把 `hr-dingxinqi.html` 里的 `API_URL` 改成 `https://api.你的域名`。注意:若产品页走 https,接口也必须 https(否则浏览器拦截混合内容)——备案前 IP 阶段,产品页和接口都用 http 即可。

## 三、日常操作(全在网页后台,不碰命令行)

- **卖出一单**:微信收款 → 打开 `/admin` → 登记订单(手机号、产品、台数 1 或 3)→ 告诉买家"打开工具页,输手机号自助领码";
- **买家换手机/清缓存要补码**:同一设备码再领 = 自动返回原码(免费不占名额);新设备码但名额满了 → 后台点该订单"重置"→ 让买家重新领;
- **接口挂了(第二层保险)**:让买家把设备码发你,双击本机的 `fama-offline.html` 生成激活码回给他——业务一分钟都不停;
- **每周一次(第三层保险)**:下载备份 `/srv/hrdx/data/orders.json` 到自己电脑(scp 或宝塔面板下载都行)。

## 四、三层保险对照

| 层 | 机制 | 效果 |
|---|---|---|
| 1 | 激活验证在买家手机本地离线完成 | 接口宕机,**所有已激活用户零影响** |
| 2 | 卖家离线发码器 | 接口宕机,新买家照常人工发码,业务不停 |
| 3 | pm2 自动拉起 + 开机自启 + 每周备份 orders.json | 进程崩溃/服务器重启自愈;最坏丢一周订单记录(码本身是算出来的,不会丢) |

## 五、常用检查命令

```bash
pm2 status          # 服务在不在跑
pm2 logs fama       # 看日志
pm2 restart fama    # 重启
curl http://127.0.0.1:8787/api/health   # 健康检查
```

## 六、验收自测(上线前跑一遍)

1. 浏览器打开产品页 → 出现激活闸,显示设备码;
2. 后台登记一个测试订单(你自己手机号)→ 产品页输手机号自助领码 → 激活成功;
3. 换个浏览器打开产品页(=新设备)→ 同手机号领码 → 应提示"已达设备上限";后台重置后可再领;
4. 打开浏览器控制台(F12),应看到 `[自检] N 项全部通过 ✓`(黄金用例 A/B 内置自动校验);
5. 断开接口(pm2 stop fama)→ 产品页自助领码应提示"接口暂不可用,请联系卖家"→ 用 fama-offline.html 手工发码可正常激活 → pm2 start fama 恢复。
