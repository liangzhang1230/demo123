# 直播间投流 · 傻瓜说明（<100 粉起号版）

> 给不拍短视频、只想靠直播起号的你。目标：花小钱，把陌生人导进直播间，找到"能留住人"的内容和节奏，再放大。
> 诚实提示：各平台工具名称和按钮位置常改，下面说的是"原理 + 典型入口"，具体以你 APP 里最新的为准。

---

## 一、用哪个工具（先认对门）

- **抖音**：给直播间投流叫 **「上热门 / 随心推」**（简单版，适合你起步），进阶叫 **巨量千川**（复杂，先不碰）。开播后在直播页面找"推广直播间 / 上热门"。
- **快手**：叫 **「粉条」**（简单版），进阶叫 **磁力金牛**。开播后找"推广 / 上热门 / 粉条"。

**记住：先用简单版（随心推 / 粉条）。千川、金牛是卖货用的，你现在不卖货，别碰。**

---

## 二、投流目标怎么选（选错，钱全白花）

投之前，工具会让你选"你想要什么"。**你现在要的是涨粉 + 人气 + 互动，不是卖货。**

- 选 **「直播间涨粉」** 或 **「直播间人气 / 观看」**。
- **千万别选「成交 / 卖货 / 进店」**——你现在不是带货，选了它，系统会给你送"想买东西的人"，不是"想听你讲的人"，钱打水漂。

---

## 三、定向怎么设（新手照这个）

- **头一两场，直接用"系统智能推荐"**，别自己瞎设，让系统先帮你找人。
- 想自己设，就这几个，别更多：
  - 年龄：25–50 岁（老板、创业者、扛压力的打工人都在这）
  - 性别：不限（老板男性偏多，也可偏男）
  - 地域：做全国就不限；只做本地生意就限同城
  - 兴趣/达人：选"财经、创业、职场、管理"这类，或者直接填几个同行大主播，投他们的粉丝
- **一条铁律：定向别太窄。** 太窄系统跑不出量，钱花不出去还没人来。先宽，再慢慢收窄。

---

## 四、一场投多少（别一次砸完）

- 冷启动测试：**单场 100–300 块，分 2–3 笔投**。比如开播后先投 100，看数据，好再追加。
- **为什么分笔投**：先投一笔当"探测器"，人留得住再追加放大；留不住立刻停，止损。
- 别一上来就大投。你现在花钱，不是买观众，是买"数据"——找到什么内容能留住人。

---

## 五、投进来之后，看什么数据决定"加投还是停"（最关键的一节）

投流把人送进来了，别光看"人多了"高兴。要盯这几个数，它们告诉你这直播间值不值得追加：

1. **人均停留 / 看播时长**：进来的人平均待多久？
   - 待得住（比如超过 1 分钟）→ 你内容能留人 → **可以加投**。
   - 几秒就走 → 内容留不住 → **停投，先改内容和节奏**。

2. **互动率**：进来的人有没有评论 / 点赞 / 扣数字？
   - 有互动 → 系统会叠加免费的自然流量给你 → **加投**。
   - 死气沉沉 → 你的钩子和"扣1"指令不够密 → 停，改。

3. **转粉率**：进来 100 个，关注了几个？
   - 转粉高 → 这波人精准、你有吸引力 → **加投**。
   - 几乎不涨粉 → 要么人不精准（改定向），要么你没给关注的理由（结尾没引导关注）。

4. **停投后的在线人数**：追加那笔投完、停了之后，人是慢慢走光，还是留下一批？
   - 停投后还有人留、还有自然流进来 → **起号成功信号，值得持续投**。
   - 停投瞬间归零 → 纯买量、没接住 → 先别放大，回去改内容。

**一句话决策口诀：**

> 人留得住 + 有互动 + 有转粉 → 加投、放大。
> 来了就走 / 不互动 / 不涨粉 → 停投，先改内容，别拿钱硬灌一个留不住人的直播间。

**（这条是大多数人投流亏钱的根：用钱去掩盖"直播间留不住人"的问题。记住——投流是放大器，你内容能留人，它放大成功；你内容留不住人，它放大失败。）**

---

## 六、算账（别凭感觉，凭数）

你的目标是"涨精准粉 + 进私域"。每场记一笔账：

- 这场投了多少钱？
- 来了多少人？留住多少？涨了几个粉？**几个进了私域（小报童/主页）？**
- 你私域转化强——所以算：**一个进私域的人，最终大概给你带来多少钱？**
- 只要"进私域的人带来的钱 > 投流花的钱"，就是正向，可以放大。
- 起号期可以先不赚钱（买粉丝+买数据），但盯着"每涨一个粉花多少钱"这个数，让它一场比一场低。

---

## 七、傻瓜执行清单（每场照做）

1. 开播，先自己播 10–15 分钟（攒几个真人、把状态和钩子调对）。
2. 投第一笔 100（目标：直播间涨粉 / 人气；定向：系统智能推荐）。
3. 盯"停留 + 互动"这 10 分钟的变化。
4. 好 → 追 100–200；差 → 停，马上改节奏（钩子更狠、扣数字更密）。
5. 每场记录：投了多少 / 来了多少 / 留了多少 / 涨粉几个 / 进私域几个。
6. 连投 3–5 场，找出"哪个主题 + 哪种节奏"最留人 → 固定它、放大投。

---

## 八、避坑（犀利版，别踩）

1. **内容还留不住人时，别大投**——那是拿钱喂水漂。先用小钱把"留人"跑通。
2. **别投"成交"目标**，你不是卖货。
3. **别把定向设太窄**，跑不出量。
4. **别三天打鱼两天晒网**——投流 + 高频稳定直播，才有复利。
5. **别指望一场爆**——投流是"一场比一场把转粉成本压低"的慢功夫，不是老虎机。
6. 工具入口/名称平台常改，以 APP 内最新为准。
