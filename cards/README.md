# 销冠底牌 · 反常识实证库 — 理论卡片系列（个人向）

面向**个人销售**的知识卡片（区别于企业向样片：企业向用纯黑+金+红的"警示/管理"调性；
个人向改用 **深墨绿ink + 翡翠绿签名色 + 极少量珊瑚红**，主打"成长 / 你能练出来"的鼓励调性）。

## 识别性（强品牌一致性）
- 左侧翡翠竖脊 + 极淡坐标网格（"实证"感）
- 顶部 `销冠底牌` 品牌 + `实证档案 NO.0XX` 档案编号
- `柱X · 主题` + 情绪标签（💰想多拿 / 🛡怕被低估 / 🕵被蒙在鼓里 / 🧭选公司 / 🔥想放弃）
- 大标题 → `▸ 数据：结论`（珊瑚红点睛）
- `“` 大引号钩子 + 标尺分隔
- `01 数据说`（大数字/图表）+ `02 扎心真相`（翡翠绿点睛）
- 论文引用条 + 证据等级点（🟢铁证 / 🟡较稳 / 🟠有争议）
- 底栏 `@销售定价学` + slogan + CTA

## 规格
- 尺寸 1080×1440（3:4，小红书信息流不裁切）
- 正文 36px（手机可读），标题 67px
- 字体 Noto Sans CJK SC

## 生成
```
node cards/shoot.mjs   # 读取 cards.html，逐卡输出 out-00X.png
```
数据在 `cards.html` 的 `CARDS[]` 数组，一条理论一个对象，方便扩展到 127 条。
