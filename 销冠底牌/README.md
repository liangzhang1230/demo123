# 《销冠底牌》主控台

把《00_主控文档 v1.1》从一份"要人读完才能干活"的文档，变成一个**打开就能干活**的系统。
单文件、零依赖、双击 `主控台.html` 即用（手机、车里、断网都行）——与体系内两个交互工具同一技术口径。

## 双极简

- **系统极简**：一个 HTML 文件，无构建、无后端、无外部依赖。`file://` 直接打开。
- **用户极简**：六个视图各答一个问题。键盘 `1–6` 切页、`/` 直达搜索、`Esc` 归位（Linear 式键盘优先交互）。

## 六个视图

| # | 视图 | 它回答的问题 |
|---|---|---|
| 1 | 总览 | 体系现状如何？下一步做什么？（127/37/90 与八柱消耗，一键跳到出单包选弹）|
| 2 | 弹药台账 | 127 条谁用过、谁没上场？（搜索 + 按柱/按状态过滤 + 勾选生成**选弹工单**）|
| 3 | 产品线 | 四层定价、八个包的状态与优先级、已知问题与待办 |
| 4 | 验收台 | 这个包能不能交付？（**自动扫描器** + §6.5 十二项人工清单 + 验收报告导出）|
| 5 | 规范速查 | 红线、三标记、结构模板、文体六条、法律免责一键复制 |
| 6 | 版本 | 版本历史与清醒剂 |

自动扫描器把 §5.7/§6.5 里机器可判的部分全部自动化：停用编号（底108/111/112）、
编号存在性（127 条白名单）、禁用词、禁用套路、无主语引用、"X大Y"凑数结构、三标记统计。
机器判不了的（数字与母本逐字一致、出处卷期页、✅ 是否真是论文结论）明确留给人工——这条边界本身就是产品红线。

## 红线合规

- 台账数据**逐字**抄自主控文档 §4（含直角引号），有独立脚本逐字比对兜底；
- 底071 / 底099 在主控文档中缺"一句话"，界面**如实标注缺失**，未补写一个字；
- 页面启动时内置守恒自检（127 条 / 37 已用 / 八柱分布 / 停用号 / 9 条重叠标记），数据不符当面报红条拒绝使用；
- 选弹工单自带铁律提示：完整数字与出处必须回《实证库_纯净版_v2.0》母本逐字复制。

## 校验

```bash
cd tests
npm i playwright-core          # 仅测试需要；应用本体零依赖
node verify-data.mjs           # 数据层：与主控文档 §4 逐字比对（127 条编号/一句话/用途）
node e2e.mjs                   # 交互层：真实 Chromium 加载，50 项断言
```

当前结果：逐字比对通过；50 项端到端断言全部通过（移动端 390×844 与桌面 1280×900、
键盘导航、检索过滤、工单生成、扫描器拦截、清单持久化、零控制台错误、无横向滚动）。
