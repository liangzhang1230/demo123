# 销冠操盘系统 · 一体版

五个独立单文件工具（定价器 v2.5 / 算账器 v3.3 / 招人器 v3.2 / 育人器 v2.3 / 留人器·信用层）合并成的一个系统。
单文件 HTML、零后端、零网络、localStorage 持久，打开即用。

## 与五件套的关系

原五件套通过「信封 JSON」（skab_v1）异步互导数据；一体版把信封换成**同一数据库上的实时总线**：

- 公司档案（城市/周期/毛利率/流失率/目标/人效）为全系统共享输入——改一处，五板块同帧换算；
- 员工/成交/线索/折扣/发放/日报/带教/协议为共享实体——算账器录一笔成交，育人器节奏台、留人器价签同时变；
- 跨板块派生实时流动：定价器 r → 算账器提成；算账器 M21/UER/DVI/P90 → 育人配方资格、留人四指数、定价造假闸；
- 留人器 AHC/M28 → 算账器闸⑪、育人产权前提；育人辅导剂量 → 留人分红四问 Q4；招人器七步链与定价器账单 B 同源同参。
- 原版的授权锁 / 免费版模糊 / 信封前置锁全部移除（数据不足时只做引导，不锁功能）。
- 全部公式、阈值、话术、📎 学术出处逐字保留，双侧系数（R-04）由架构天然同步。

## 使用

直接打开 `../销冠操盘系统.html`（或 `dist/index.html`）。首次打开自动载入演示数据（10 名销售近 7 个月完整流水，
保证所有诊断点亮）。数据中心可清空 / 重载演示 / 导出导入全量备份。

## 开发

```bash
node build.mjs        # 拼接 src/ → dist/index.html + ../销冠操盘系统.html
node tests/e2e.mjs    # Playwright 全站巡检 + 联动断言 + 持久化 + 对拍自检
```

`src/` 按文件名顺序拼接：00 样式 → 01 内核(SK) → 02 UI 外壳 → 05 驾驶舱/数据中心 → 10–14 五模块 → 99 启动。
模块契约见 `KERNEL-API.md`。`originals-*.html` 为五件套原始归档（对拍事实源）。
