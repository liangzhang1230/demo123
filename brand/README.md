# 老良人价 · 品牌标识资产

「人」字为骨，天平为意：横梁以 8° 定角穿过字顶，朱砂支点落在人与价的交汇处。
完整规范见 [`brand/index.html`](./index.html)（可直接用浏览器打开）。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `logo-mark.svg` | 主标记（浅底彩色） |
| `logo-mark-mono.svg` | 单色版（传真 / 雕刻 / 单色印刷） |
| `logo-horizontal.svg` | 横版组合（导航栏、页眉、名片） |
| `logo-vertical.svg` | 竖版组合（封面、海报、启动页） |
| `logo-avatar.svg` | 反白圆形头像（社交账号、App 图标底稿） |
| `favicon.svg` | 小尺寸专用（16–48px，笔画已加粗） |

## 色彩

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨 | `#1A1A1E` | 主色、笔画、正文 |
| 朱砂 | `#C93A2B` | 支点、强调（浅底） |
| 朱砂 · 亮 | `#E05A44` | 支点（深底反白） |
| 纸 | `#F7F5F0` | 底色、反白笔画 |
| 石灰 | `#8A867E` | 辅助文字 |

## 注意

- 横版 / 竖版组合中的文字依赖系统字体（宋体 / 黑体栈）；对外正式交付前请在设计软件中将文字转曲。
- 请勿改变横梁倾角、笔画比例，或将朱砂用于大面积底色。
