# 全球头部同类软件设计借鉴清单 → 育人器落地映射

调研范围：销售教练/赋能头部（Gong、Mindtickle、Salesloft、Ambition、LevelEleven、Highspot）、
销售绩效管理（Xactly、CaptivateIQ、Everstage）、极简设计标杆（Linear、Superhuman、Stripe Dashboard）。
原则：**双极简**——系统极简（零依赖、一套令牌、一个渲染循环）+ 用户极简（每屏一件事、空态即教学、证据即出处）。

## 一、信息架构

| 借鉴 | 出处 | 落地 |
|---|---|---|
| 行为证据 → 结构化评分 → 教练动作 三层枢纽，而非平铺报表 | Gong Scorecards / Highspot Rep Scorecards | 日报四计数（证据）→ PLV/PSI（评分）→ 处方/带教任务（动作），屏④→⑤→⑥单向流 |
| 经理首屏 = 分诊台：异常人名 + 待办直达，不是报表墙 | Gong coaching workflows | 屏①「今日分诊台」：动量/弃赛/挂账/新人红警/JOLT/资历忽视六类预警，每条一键直达 |
| 首屏 5–9 元素强约束、细节渐进披露 | Stripe Dashboard / SaaS 仪表盘研究 | 销售端整屏 ≤5 卡；老板端每屏一个主任务，明细折叠进表格 |
| 就绪度聚合：一人一个缺口清单 | Mindtickle Readiness Index | 处方诊断"量差/质差/速差取偏差最大"，一人一型一动作 |
| 诊断必须自带药方 | Mindtickle 补救自动化 | 系统建议稿（已过三层）+ 一键派发；散点图点人直达处方 |

## 二、经理端 vs 销售端分离

| 借鉴 | 出处 | 落地 |
|---|---|---|
| 同一数据两个叙事：Rep 看自己进步，Manager 看横向异常 | Gong rep/manager dashboards | 老板端八屏有排名与预警；销售端零排名、零对比、零红灯（A-08/A-09），仅"我的处方/配对/悬赏" |
| 销售端只回答"我在什么节奏、接下来做哪件事" | LevelEleven / Everstage | 销售端 = 处方卡（三段）+ 四计数一键提交 + 配对日程 + 供氧卡 |
| 透明化换信任：拆解可查、规则公开 | CaptivateIQ | 每个考核类页面写明规则（A-02）；闸⑧/闸④判定条件全文可见；抽检页脚"全员同规" |

## 三、指标呈现与教练工作流

| 借鉴 | 出处 | 落地 |
|---|---|---|
| Pacing 四态配色按"应有进度"折算，颜色即预警 | LevelEleven scorecard pacing | M43 四区（保护/加速/常规/弃赛）四色看板；弃赛区自动生成"能赢的小仗"子目标 |
| 评分只评可训练的语言行为，不评结果 | Gong 行为评分卡 | PLV 三层：拦人身词库 → 去人名测试 → 三槽位（数据/动作/基准）；处方永不挂钱 |
| 教练留痕可归因 | Ambition Coaching Orchestration | CoachingAck 回执链 + 14 天回弹定稿 + 配对组 90 天差回流 M26 |
| 游戏化反噬：排行榜驱动刷量 | Ambition G2 差评教训 | M14 有效动作分（min(线索, 意向÷带宽)）：刷量数学收益归零；量增质塌抽检加权×3 |

## 四、极简视觉规则（Linear/Superhuman 谱系）

- 近黑文字 + 纸白底 + **单一强调色只做手电筒**（主按钮/当前导航/焦点）；语义红黄绿只给闸与节奏区，不做装饰。
- 一套 token：一种圆角、一种阴影、一档边框；间距 4/8px 刻度；字重 400–600 窄带，靠字号与留白分层。
- 数字全部 `tabular-nums` 等宽对齐；金额分存元显、万元一位小数（公约【2】）。
- **空态即引导**：每个锁定/空屏 = 图标 + 一句为什么 + 一个下一步按钮（"去导入算账器信封"）——锁定态诚实披露解锁条件，兼作渐进披露。
- **解释性 UI**：每条建议卡自带 📎 出处行（A-22），"why am I seeing this"就地回答。
- **本地优先必防丢**：>14 天未导出顶部黄条 + 启动配额自检 + 迁移说明入口（A-24/C-15）。

## 五、本项目的差异化（头部产品没有的）

1. **PLV 处方语言校验器**：Gong 只评分通话，本品在"老板写反馈的那一刻"实时拦截指向人格的语言——把 Kluger & DeNisi 的结论做成了输入框级别的产品。
2. **配方源资格核弹**：头部产品默认"业绩第一 = 学习对象"；本品用 M21 归一化 + UER 把"地盘肥"与"真本事"分开，拒绝把漏水规模化。
3. **闸⑧挤出对冲**：悬赏可以发钱，但必须同时留一条不发钱的承认路径（静默认可通道）——"不是不许用钱，是不许只有钱"。
4. **19 条对拍徽章自检页**：健康检查页做成可收货标准，客户不懂代码也能验收。
