# 件三 · 函数库（唯一权威口径；对拍常量即验收）

## 3.1 F1 · 产能算钱器（七步链，含双算法）

```ts
// 算法A 天真（系统自己跑老板脑子里的，🔴 不问老板）
naiveHires = ceil(Z1/Z2) − Z3
// 算法B 六步
①需要满产当量 = Z1/Z2
②新人年贡献率 k(m) = newHireYearRate(Z4, m)          // 计划入职月 m，默认 1；k(1)=全曲线
   kEff(m) = k(m) × (1 − Z5 × getCoef(midYearAttritionFactor))   // 🔧Z-C06 新招的人自己也会流失（年中折半）
```
