# 件一 · 产品定义

**一句话定位**：他要走，是因为你没给他钱，还是没给他饭吃，还是——不信你？留人器把"留人"从酒桌玄学变成四个可计算指数（SII 监督/EI 授权/DVI 可见/**AHC 老板信用分**）+ 一套产权机器（M28）+ 三台事件预警器（参照点/余震/榜眼）。**全球所有销售软件都是老板监督员工，只有这一个，让员工每天看见老板的信用分——而这恰恰是 Hart 诺奖第四定理的唯一可信实现。**

**目标用户**：老板端（主）+ 销售端钱途页（只供氧）。**落地页边界声明**：『这个系统不会让一个卖不动的产品卖动。如果你的产品本身有问题——先去改产品。』

**系数性质声明**：系数为全球实证基准值（见文末锚点索引），中国系数校准中；可在系数页按行业覆盖。
