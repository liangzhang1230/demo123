## 2.2 存储实体（前缀 `skab_suanzhang_`；共享实体命名遵公约 §1）

**Deal**：`dealId / employeeId / dealDate / entryDate(录入日，DVI用) / paymentAmt(回款,int分) / categoryId / leadSourceType(SE-03|null) / note`
**Category**：`categoryId / name / grossMarginRate(0–1，成交时快照进 Deal 计算)`
**PayoutEntry**：`payoutId / employeeId / payoutDate / type(SE-01) / amount(int分) / timing(SE-04，仅 discretionary 必填) / hasCondition(bool，仅 discretionary) / note`
**RefundEntry**：`refundId / employeeId / refundDate / categoryId / amount(int分) / note`（🔴 不红冲、不对照原单、不倒扣提成；报表两层=原始累计回款/核算营收）
**DiscountEntry**：`discountId / discountDate / employeeId(🔴降价必须有名字) / dealId|null / categoryId / listPriceAmt / actualPriceAmt / discountAmt(自动=差) / reason(SE-02)`
**LeadAssignment**：`laId / employeeId / month(YYYY-MM) / assignedLeads(int) / selfDevLeads(int) / sourceType(SE-03)`（无派单系统=老板月度录入 🟡B；有=🟢A）
**OpCostItem**：`ocId / name / kind(SE-07) / monthlyAmt(int分)`（按天摊；🔴 闸④：成交类产品成本禁止在此重录）
**ManagerChangeEvent**：`mcId / teamId / newManagerId / changeDate`
**PlanPeriodConfig**（单例）：`periodType(SE-06) / commissionThresholdAmt(int分|null)`（M34 用；null→聚集指数"—"）
**ProcessBaseline**：`pbId / metricName(如"电话数") / baselineValue(int) / source('local'|'imported') / bookedDate|null`
　`source='imported' 由导入定价器信封 PendingEvidence 自动建【桩】(bookedDate 带入、metricName/baselineValue 留空)；M36 出卡线率前必须由老板补录 metricName 与 baselineValue（UI 强制），否则该指标显"待补录你设的底线数"。`
**EliminationConfig**（单例）：`basis(SE-05) / survivalMonths(int,默认3) / survivalLineAmt(int分|null，null→默认取该员工月 laborCost)`
**Salesperson**（本板块补充字段）：`socialCostRate 覆盖(可选)`；员工离职登记复用 2号 ZE-05 枚举。

**🆕 ExternalRef**（S-C06/S-C09；按 board 一条，共 4 条上限：dingjia / zhaoren / liuren / yuren）：
`board / exportedAt(YYYY-MM-DD，取自信封) / dataVersion / coefficientsHash / derived(派生标量快照，见 §3.13) / importedAt`
　🔴 **只读缓存，本板块永不回写对方字段**；同 board 再次导入 = 整条覆盖（不做合并）；`coefficientsHash` 与本机不一致 → 顶部黄条"系数表与{board}不一致，建议同步"（不阻断导入）。
　🔴 **M28Agreement 走 entities 通道**（它是公约表A 第 26 号实体，非派生标量），导入后只读存放，不进本板块编辑界面。
