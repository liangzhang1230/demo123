# 件一 · 产品定义

**一句话定位**：中国中小企业老板的销售人力总算盘——输入 13 个数，5 分钟看清"定薪该定多少、该招几个人、走一个人亏多少、缺几个主管、团队奖该不该发"，算出今年已注定的漏损总额；系统同时替你把方案对一遍最低工资与劳动法红线；再把方案送进"风洞"，预演它会被怎么玩、会筛进什么人、会诱发什么造假。

**目标用户**：10–50 人销售团队的老板本人。
