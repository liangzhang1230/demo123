## 2.2 存储实体（前缀 `skab_yuren_`；共享实体遵公约 §1）

**DailyReport**（公约写方=本板块）：`drId / employeeId / date / counts{leads,intents,samples,contracts} / submittedAt`——休息日不催不计（排班表 ShiftConfig：员工×星期几）。
**Prescription**：`rxId / employeeId / date / type(YE-02) / target(YE-03) / slotData{behaviorData,action,benchmark}(三槽位结构化存储) / text / psiParts{targeting,benchmark,dataRef,ackRate} / plvPassed / coachAckId|null`。
**CoachTask**：`ctId / employeeId / managerId / stage(环节) / createdAt / managerReportedAt|null / reboundDue(created+14d) / reboundResult(YE-05)|null`——同人同环节 7 天不重复；完成=主管上报∧CoachingAck confirmed。
**Bounty**：`bountyId / template(YE-04) / params / amountAmt(建议制) / active / achievedEvents[]{employeeId,achievedAt,cashedAt|null}`——同时活动≤3；达成判定纯事件流。
**SpotCheckCard**：`sccId / weekOf / employeeId / checkDate / stage / reportedCount`——只出题不记结果，无造假字段。
**RecipeSource**：`sourceIds[](1–3人合成均值) / setAt / setBy / qualifiedFlags`——每次设定必过闸④。
**PairAssignment**：`pairId / weekOf / coachId / learnerId / topicStage(该 learner 偏差最大环节) / status(YE-08) / consecutiveWeeks / coachAckId|null`。
**MomentumState**（派生视图）：按人计算连败数/赢率降幅/负动量分，无独立存储。
**CallMetrics 🟤**（公约埋设实体，本版只建表不建界面）：`cmId / employeeId / callDate / talkListenRatio / questionCount / durationSec`——🕐 点亮条件：接入录音数据源。
**PaceConfig**（单例）：`periodType / quotaSource`——完成度=周期内回款÷个人配额（配额来自定价器信封或手工）。

# 件三 · 函数库（唯一权威口径）

## 3.1 M12 配方引擎全链
**闸④ 配方源资格（硬闸，全系统最锋利的一刀）**：候选必须同时满足 ①M21 归一化排名∈前3 ②UER≥0 ③折扣泄漏≤团队均值 ④客诉/退款≤团队均值；任一不满足→拦截（话术 Y-01：拒 A 表+荐 J 表+『这不是在复制销冠，是在把一个人的漏水规模化』+『而 J，就是那个你三个月前正准备开掉的人』）；M21 未运行→配方引擎整体锁定。
**闸③ 产权前提**：配方源无 M28 协议 ∨ AHC<60 → 锁定（话术 Y-02 含产权四件报价：署名免费/使用费 3.5 万/带教分成 3.48 万 69.6 倍/irrevocable）；上线后配方源 UER 趋势 <−0.5σ → 🔴『他开始藏了』。
**三张牌蒸馏**（每月日切自动重算，零新增录入）：剂量=近6月日报计数÷有报工作日；配比=四环节累计制转化率；节奏=首单日/出单间隔/品类占比。首 N 天基准=配方源+历史达标者（归一化判定；样本<3→单人+标注）。量×质散点四象限（横轴=🔴有效动作分）。
**每日处方三段**（入职≤90天首屏第一卡）：对标段→诊断段（量差/质差/速差三型按 rxRules 取偏差最大；量差给本人补 n 动作、质差生成带教任务、速差老板插卡每人一次）→回执段（连续达成仅展示）。页脚固定灰字：『处方为成长参考，不构成考核依据。』
**带教任务**：同人同环节 7 天不重复；14 天单次回弹定稿（rebound/flat/worse）汇入育人器"带教有效率"（🔧Y-C03：此为主管作为教练的产出证据，不等于算账器 M11 的归一化回款 ratio）；完成=主管上报∧销售 CoachingAck confirmed（no_response 7 天自动 confirmed；disputed 不计剂量+进老板异议列表）。
