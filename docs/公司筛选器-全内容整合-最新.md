## 1. 产品真实功能（名实一致的底稿）

> 一切文案不得超出这一节。工具**评估的是一份 offer / 一家公司的数据**，不是"看人""选人"。

**核心洞察**：求职者拿不到公司内部数据，能输入的只有 JD / 面试 / 聊天里给的那几个数字。本工具**不假装看透公司内部**，而是**把招聘方给出的承诺做压力测试**，算出真实期望值并识别陷阱。

### 1.1 三个模块

| 模块 | 干什么 | 一句话 |
|---|---|---|
| **找** | 评一个 offer | 它到底值多少、有没有坑 |
| **选** | 多个 offer 并排比 | 该去哪个，一眼看清 |
| **留** | 要不要走 / 下家行不行 | 算清空窗成本，别裸辞踩坑 |

### 1.2 输入（极简 3 分钟）

城市档 · 底薪 + 底薪性质（无责 / 有责 / 零底薪）· 提成率 · 提成基数（回款 / 毛利 / 标价）· 综合毛利率 · 成交周期 · 试用期 · 提成兑现率 · HR 画的饼（可选）。

> 关键坑点，文案可反复用：
> - **有责底薪** = 要完成任务才发，它其实不是你的安全底。
> - **按毛利提成** = 名义提成率会被毛利率打折——最大的坑。
> - **纯冷启动** = 公司拿你的时间做市场测试，期望成交要打折。

### 1.3 输出

1. **冷静期望月收入**（稳定后）= 底薪 + 期望月提成
2. **达标概率**（那个"过万"到底多少人真做到）
3. **前 6~12 个月现金流**（底薪能不能撑过爬坡期）
4. **七维体检分** + **红线提示**（底薪违规 / 提成缩水 / 定额虚高 / 长周期陷阱 / 隐性减薪等，自动亮灯）
5. **该不该去**：🟢 可以去 / 🟡 慎重（有坑可谈）/ 🔴 别去 —— 一句话结论

### 1.4 营销简化对照（外化说法 ↔ 工具真实项）

| 外化说法（图/标题里用） | 对应工具真实输出 |
|---|---|
| 到手真数 | 冷静期望月收入 |
| 达标概率 | 达标概率 |
| 3 条红线 / 自动亮灯 | 红线提示 + 一票否决 |
| 体检分 | 七维体检分 |

> 简化可以，**不能造假**。凡是工具算不出来的（例：具体某公司好不好、保证你能拿多少），一律不写。

## 3. 短刀 · 钩子（一句话；评论区 / 笔记开头 / 视频开场 / 主图）

**① 差距流**
> 同一届毕业做销售，他月入 3 万你月入 8 千。同样加班、同样跑客户。差距在哪？——三年前选公司那一下，他跑了数据，你用了"感觉还行"。

**② 简历流**
> 你简历上"三年四家公司"，HR 划过去只想四个字：这人不稳定。她知道你每次离职都是因为公司烂吗？不知道。但分，已经扣完了。

**③ 成本流**
> 面一次打车 50，面十家 500。车费花了、时间花了，最后你还是挑了最烂的那家。你选公司的工具是"感觉"，你同事的是数据。

**④ 焦虑流**
> 最难受的不是加班，是凌晨两点你还在刷招聘软件——明知现在这家待不下去，却分不清哪家才是好公司。这种焦虑，你还要忍多久？

**⑤ 短刀**
> 选公司靠感觉，就是闭眼开车。你开了三年，撞了几回？

**⑥ 反讽**
> 你面试时说的每句"想找更好的平台"，翻译过来都是"上家是个坑，可我当初没看出来"。——下一次，你可以看出来。

**⑦ 体检梗**
> 体检你都知道要看报告单。选一份赌上一年的工作，你却凭"感觉还行"。
