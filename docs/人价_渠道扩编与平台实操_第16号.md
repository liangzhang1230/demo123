# 第一部分 · 讲师副业判决与15分钟试讲视频

## 1.1 判决：该做，但当侧翼

**支持做的事实：**
- "销售定薪+快速筛人"是**稀缺交叉位**【经验/推测】：现有薪酬课（张守春3E薪资、蔡巍绩效薪酬）全是HR背景讲师讲给HR听的通用体系；从销售团队搭建实操角度**讲给老板听**的，没人占位。
- "以训代咨"被验证：行动教育（A股上市）就是3.98万/人的课做前端、咨询陪跑做后端，转介绍率85%【数据】。课是"可被低成本体验的咨询样品"。
- 你担心"招聘筛人像人事干的活"——**定位解法：不讲招聘流程（那是HR的），只讲老板的三个决策**：底薪标多少才有人来（定价）、提成怎么设人才会跑（导向）、第几天必须判断去留（止损）。这是老板决策课，不是HR操作课。

**泼冷水的事实：**
- 新讲师从材料齐备到第一笔课酬通常**3-6个月**、金额5000-15000元【经验】——救不了8月底的现金流，所以它是侧翼。
- 机构渠道台下多是HR和中层，**不是买你咨询的老板**。
- 机构分成重：企业付款的50-70%才到讲师手【经验】；课后30-90天账期、拖欠不少见——协议里写"课前预付50%或课毕当日结清"。
- **课酬锚定风险（最重要）**：若以5000元/天的价格大量讲课，客户会用"天数×课酬"心算你的咨询报价，8-25万的重建项目锚被压死。纪律：**对机构报1.5万/天起**（"面向老板/高管的课15000元/天左右起"是可查行规【数据】），宁可少接。

**结论：判断这条线成败的指标不是课酬收入，是每场课带来几个诊断线索。**

## 1.2 15分钟试讲视频（本周录，一条视频三处用）

**选题定名：《销售团队定薪与快速筛人：让业务员自己跑起来的3张表》**（课名带结果和人群，明确"讲给老板/销售VP"，避开与HR课正面竞价）

**逐段脚本框架（15分钟）：**

```
0:00-1:30  钩子+身份
   开场即问：「你们每个月最后三天的成交额，占全月多少？」
   停两秒。「答不上来这个数的老板，你的提成方案从来没人替你算过账。」
   一句身份：20年销售组织操盘手，只研究一件事——人的定价。

1:30-6:00  第一张表 · 定薪表（底薪档位）
   讲1号案例骨架：5000招不到 → 老板自己试6000还是招不到 → 8000第4个月整体盈利
   给规则：底薪加价50%以内基本无效（无效加薪阈），当场画三档表。
   金句：「你以为在招人，其实一直在标价。」

6:00-10:30  第二张表 · 提成导向表
   阶梯vs线性：阶梯教人压单（月底冲量+打折），线性+率差教人卖对的产品
   实例：19800提5% / 38000提10%——高毛利提成翻倍，高毛利卖得最好
   金句：「要拉开差距别在时间上拉，那叫压单；要在产品上拉，那叫导向。」

10:30-14:00  第三张表 · 筛人表（快速判定）
   试岗3天/日薪100元/15天封顶判定
   算账给老板看：判定成本300-500元 vs 拖三个月=底薪+机会成本几万块
   金句：「筛人不是面试面出来的，是让他干三天干出来的。」

14:00-15:00  收尾（两个版本分开剪）
   机构版：总结三张表，报课程完整版大纲（0.5天/1天），不带任何私域钩子
   传播版（视频号/老客户转发用）：扫码领《销售薪酬健康度自测表》+
   每月限量的30分钟免费诊断
```

**拍摄规格【数据/经验】**：画面含**半身+PPT同框**（机构选师的硬要求）；15分钟是入库下限，机构实际看3-5分钟就下判断——所以前5分钟必须出现具体数字和表格，忌念PPT、忌理念鸡汤。手机+领夹麦+顺光即可，不要为设备耽误一天。

## 1.3 发给培训机构的三件套与话术

**三件套：** ①讲师一页纸（头衔+20年实操+三条量化战绩，数字开头）②标准课纲（0.5天/1天两版，含课程收益/大纲/案例/适用对象）③15分钟视频链接+报价（1.5万/天起，可谈）。

**发给谁：** 搜"你所在城市+管理咨询公司/企业培训公司"，找**师资部/课程顾问**（官网电话、企业微信均可）；目标50-100家中小机构批量发。大机构（聚成/行动教育）以自有名师为主，新人别浪费时间；华师经纪、京师堂类讲师经纪公司可投但会要求排他【经验】。

**微信/邮件逐字话术：**
> 「您好，我是老良，20年销售团队操盘手（自己创业带过几百人销售团队，帮多家企业重建销售体系、最快第4个月扭亏）。我有一门给老板讲的课：《销售团队定薪与快速筛人》，0.5天/1天两版，附课纲和15分钟试讲视频。这个选题目前市场上都是HR视角的薪酬课，从销售实操角度讲给老板听的很少，比选时容易中。首次合作可以先给贵司的会员企业沙龙免费讲一场90分钟，效果您现场看。课酬和合作方式视频后聊。」

**"免费首讲换入库"是行规【经验】**，但只送90分钟沙龙版，不送整天课。

**两条红线：** ①通过机构接的课，**学员是机构的客户资产**——私下收联系方式、现场推销咨询会被全行业拉黑；合规做法是"扫码领自测表"型公开工具（自愿领取），或事先与机构书面约定咨询线索分成。②**不给中华讲师网/讲师宝类平台交年费**——它们主要是向讲师收费卖曝光的生意，"百强讲师"付费榜单2026年正被监管专项整治【数据】。

## 2.4 渠道测试记分板（Bullseye法【数据·Weinberg & Mares《Traction》】）

你说"落地不知道快还是慢，需要测试"——测试本身要有纪律，否则23条渠道会把你撕碎：

```
规则1  同时在测的新渠道 ≤3条（单人精力上限）；15号主线三条（0号/老客户/商会）不算测试，是必做
规则2  每渠道最小测试单元：谈成3个合作方 或 办完1场活动 或 完成10次有效接触
规则3  测试周期：30天一轮
规则4  北极星指标：付费诊断单数量（¥19,800到账），不是线索数、不是加微信数
规则5  淘汰线：30天0场老板级对话→立即淘汰；有对话无提案→改话术再测30天；
       时间成本折算后CAC>诊断毛利→降级为维持态
规则6  一张看板每周日更新：渠道 | 接触数 | 老板级对话数 | 提案数 | 成交数 | 耗时
规则7  《Traction》核心洞察：任一阶段总有一个渠道显著优于其他所有渠道——
       找到它之后资源全压上去，其余降为维持态，不搞雨露均沾
```

## 3.2 BOSS直聘：合规边界先说清（这段必须读完再操作）

**平台规则的事实【数据】：** 注册协议要求"以招聘和/或求职为目的"使用；平台2026年在持续封禁"诱导至站外、索要微信"类账号（1-5月处置超6000个，90%由AI风控主动拦截）。**以纯营销为目的使用BOSS，本质上违反用户协议，账号随时可能没收——你自己也说了封号风险，这个判断是对的。**

**合法的窗口在哪：** 你的"半驻场督导"产品（每周2天、月费制）**本来就是一种兼职高管工作形态**（对标美国 fractional VP of Sales）。你以候选人身份应聘"销售总监/销售VP/销售合伙人"岗位、在面谈中提出"我可以用每周2天+按月合作的方式帮你把团队建起来"——这是候选人和雇主协商用工方式，属于真实求职行为的延伸，和拿平台当广告板有本质区别。

**操作纪律（保号五条）：**
1. 只应聘岗位、只聊岗位本身和对方团队现状；**站内文字永不出现报价、服务名、"咨询/诊断"字样、微信号**。

## 3.4 招呼语（≤200字要求下，最优其实是60-100字）

**先校准预期【诚实】：** 没有任何公开的招呼语A/B实验数据；"基本100%获得回复"不可能——对方未读、停招、岗位关闭天然存在。现实基准：泛发模板10-20%；**高度定制+老板直招活跃岗+数字开头，40-60%已是天花板级**；"已读回复率"做到70%+就是话术极限。任何宣称100%的都在筛分母（只统计已读或活跃岗）。把回复率推到上限的结构【经验】：**15字内亮点开头 + 30-50字匹配说明 + 量化战绩 + 针对该公司一句 + 提问收尾，总长60-100字。**

**版本A · 制造业/工业品老板直招销售总监（主力版，约90字）：**
> 20年销售团队操盘手，上一家从底薪5000招不到人做到第4个月整体盈利。看了贵司在招3个销售岗——先问您一个数：咱们每月最后三天成交额占全月多少？这个数能看出团队问题的一半。方便的话约个电话，我把我的打法讲给您听。

**版本B · 岗位挂了很久/反复在招（痛点版，约85字）：**
> 这个岗挂了有段时间了吧——销售总监难招，多数时候不是缺人，是薪酬结构让好手不敢来。我20年专做销售团队重建，最快第4个月扭亏。您如果是老板本人，值得聊15分钟，我先说说我看到的问题。

**版本C · 销售合伙人/城市合伙人岗（合作倾向版，约80字）：**
> 合伙人岗我有兴趣。20年销售操盘：定薪、提成设计、快速筛人是我的三板斧，带过几百人团队，也帮企业从零建过队。我不要空承诺，先看贵司数据再谈怎么合作——您方便约个电话吗？

**使用纪律：** 三版按岗位类型轮换，每版发出≥30次后统计回复率，留强杀弱；每条针对对方公司加一处定制（行业/在招岗位数/产品），纯模板必死；发出时段8:30-10:30优先。

# 第五部分 · 这次你没想到的八件事

1. **专家网络是被你完全忽略的最快现金**：凯盛/GLG/高临的付费访谈到手1500-3000元/小时，门槛只是"有行业一线经验"，2-6周首单——每月做3-5个小时访谈就是小几千到上万的底粮，且访谈方是投资机构，与你的客户零重叠。唯一注意：只谈自己的行业经验，勿碰前客户机密（凯盛2023年因数据安全被查后已收紧涉敏访谈）。
2. **中小企业服务券=政府替你打折30%**：入库后客户买19,800诊断实付约1.4万，还自带官方背书。窗口期错过等一年，本周就去查本地经信/工信部门的征集公告。
3. **猎头是你天然的同盟不是同行**：老板对猎头说"帮我招个销售总监"，背后往往是体系问题——猎头做不成、或做成了人留不住的单子，正是你重建咨询的完美线索；你的重建项目要补人时单子回流猎头。这个双向结构比任何返佣都稳固。
4. **课酬锚定效应**：讲师副业最大的隐性代价不是时间，是价格锚——5000元/天的课讲多了，25万的项目就再也报不出去。1.5万/天起报是防线，不是姿态。
5. **BOSS直聘的正确心态是"借用"不是"依赖"**：它违约成本在你这边（账号说没就没），所以永远保持三条以上并行渠道，并让BOSS聊到的老板尽快沉到你自己的微信里。
6. **"100%回复"的分母真相**：所有教你100%回复的教程都在偷换统计口径。你要追求的不是回复率数字，是**每天2-3个老板级对话**这个绝对量——15-25个精准开聊×40-60%已读回复率就够了。
7. **一条视频三处用**：15分钟试讲视频同时是①机构入库材料②视频号/朋友圈信任资产③老客户转介绍时"递得出手的凭证"——录一次，剪两个结尾（机构版收尾中性、传播版带自测表钩子）。
8. **渠道多不等于好，测试有配额**：23条渠道里你同时能认真跑的新渠道只有3条。真正的杠杆是2.4的记分板——30天一轮生死判，找到那条"显著优于其他所有渠道"的冠军渠道后全压，其余降维护。渠道测试的失败模式不是选错，是全都想要。
