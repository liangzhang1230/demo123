# 第一部分 · 赛道终审（再次确认）

## 1.1 判决：赛道成立，双层结构，现金先行

**对外卖的（现金层）：销售团队诊断+重建咨询。** 老板买的是"我的销售团队出了问题/我要建销售团队"这个结果，不是"人才定价"这个概念。你20年干的、0号1号2号案例证明的、老板愿意马上掏钱的，都是这个。

**支撑卖的（品牌层）：销售人才定价（人价）。** 它回答"为什么找你而不找培训师/猎头/薪酬公司"——你的诊断从工资条切入、三分钟可验证、不依赖背书。它是差异化武器和2-3年的品类资产，**但它自己不是30天的现金来源**。

两层不冲突：**诊断卖的就是人价方法论，只是收钱的名义写"销售团队诊断"。**

## 1.2 论证（新证据）

- **这个赛道有一个活了25年的单人标杆。** 美国 The Cygnal Group（Donya Rose），1999年起单人只做"销售薪酬方案设计"一件事，客户从创业公司到数十亿美元企业，获客靠150+条问答内容库+行业协会演讲，零广告【数据·官网自述】。**单人、无机构、只做销售薪酬——被验证可以活得很好。**
- **复购机制有行业共识背书。** SalesGlobe 公开主张"薪酬方案每年评估一次、每2-3年全面重设计"【经验】——你的"守"（年度体检）不是自创名目，是行业标准动作。
- **April Dunford 路径确认了顺序。** 她起步期先做"又累又杂但有钱"的泛化咨询，几年后才把方法论产品化成固定价工作坊（早期约$10-15k，出书后$60-80k）【经验·本人口述】。**先用现金活下来，再产品化，再涨价——不是反过来。**
- **PE渠道真实存在但是第二曲线。** Blue Ridge Partners、Alexander Group 都有专门服务PE的销售薪酬业务；全球85%以上PE机构使用外部独立顾问【数据】。但中国人民币基金投后采购靠关系网攒局、付费主体是被投企业、冷启动周期3-6个月【推测】。**播种今天就开始，收获别指望30天内。**

2. **联名调研报告**：《XX商会会员企业销售薪酬调研》，商会出名单你出方法论，报告署名联合发布——这是商会的标准动作（协会本就靠行业报告做会员服务），也是你的"State of X"小数据资产【数据：原创数据报告是B2B获客最强资产之一，73%的B2B买家认为思想领导力内容比营销材料更可信——Edelman-LinkedIn】。
3. **现场表演设计**：首讲保留15分钟"当场算三个数"——请一位老板现场报数（月底三天占比/主管vs销冠收入/销冠留任），当场推算病灶。这是"公开诊断"模式：英国 Roast My Landing Page 靠公开点评零背书累计约30万美元营收【数据】。**无背书者的信用=当众把病看准。**

时间线【推测】：接触秘书长→首讲2-4周；首讲→第一单诊断1-2个月。

## 6.3 PE投后（今天播种，不指望本月）

- **话术军火**：Bain 2023研究（SBI引用）：商业卓越举措是PE被投企业收入增长第一驱动力，平均带来27%收入提升【数据】；Alexander Group 给PE做"被投企业销售薪酬统一化"是成熟产品——**"销售薪酬"服务PE在全球是被验证的生意，中国投后正缺这个外挂。**
- **现实路径**：在老客户和商会圈里问一句「你们公司有没有机构股东？」→ 有机构股东的企业做出结果 → 请老板把你引荐给基金投后负责人（头衔认准：投后管理部总经理/运营合伙人/投后总监）→ 批量引荐被投企业。付费方是被投企业，不是基金【推测】。
- **一页纸**：本月备好《给投后负责人的一页纸》：你是谁+三个数诊断+被投企业案例(有了就填)+27%数据锚。
- **红线**：市场化基金投后人员个人返佣同样触碰非国家工作人员受贿——给机构层面价值（被投企业优惠价、联名内容），不给个人钱。

## 6.4 银行（第3个月后，零投入原则）

给客户经理个人任何好处费=非国家工作人员受贿罪，有判例（信贷员收好处费获刑5年4个月+终身禁业）【数据】。唯一合法姿势：免费给对公团队/私行沙龙讲课换曝光，或银行对公采购你的课。借商会场合自然结识支行行长/对公团队长即可，不主动投时间。

## 6.5 产业园区（第2个月起）

园区企业服务专员缺内容有KPI，免费讲座一周可敲定【推测】；但听众常是HR不是老板——**报名环节必须要求"创始人/销售负责人本人到场"**。价值在攒背书（"XX园区企业服务专家"）与入库铺路（北京/上海/江苏都有服务商入库机制【数据】），不在现金。

# 第七部分 · 精准触达老板（BOSS直聘之外）

## 7.1 名单构建

- 企查查/天眼查/爱企查高级筛选：**行业 + 地区 + 参保人数30-200 + 正在招"销售/销售经理"**。"在招销售"是最强意向信号——正在为销售团队花钱的企业。
- 替代源：1688找工厂（店铺直接有联系方式与规模）、展会会刊/展商名录（E展网等可下载）、商会会员名录、政府"专精特新"公示名单（全公开合规）。
- **这些工具给你的是"企业名单+公司座机"，不是老板手机号。老板本人靠下面的通道。**

## 7.2 三条触达线（30天内只做这三条）

**① 转介绍引擎（40%精力，成交率最高）**
【数据】引荐线索转化率15-25%（冷名单1.5-2%）、赢单率40-60%、成交速度快4-5倍。系统化四动作：
- 时机：客户表达满意的**当下**开口，不等；
- 话术给具体画像：「您认识的老板里，有没有哪位正为销售团队发愁的？比如做XX行业、团队十来个人、招不到人或者有人不出单的？」——具体画像让对方脑中浮现具体的人；
- 降低成本：替介绍人写好那条转发微信（线②话术最后一段就是）；
- 回报给荣誉不给回扣：「介绍成了，我免费给你做一次年度体检」比介绍费体面有效。

**② 行业展会（30%精力）**
中小企业展位上站着的常常就是老板本人——全中国唯一零门槛面对面逮老板的场景。观众身份免费进场，提前用会刊筛目标展商，开场「我在研究贵行业销售团队的薪酬结构」，聊5分钟加微信。一场展会2天可加30-80个老板微信。

**③ 顺丰"亲启"包裹（30%精力，被严重低估）**
【数据】立体/异形直邮对B2B平均回应率8.5%（部分研究10-15%），开启率95-100%，约为冷邮件的36倍以上。打法：从名单选50家最优 → 顺丰寄「XX公司 王总 亲启」：《销售团队薪酬十大病灶》小册子（就是你十几个观点的大纲版）+ **手写便签** + 微信名片卡 → 3天后打**公司座机**：「我给王总寄了一份行业销售薪酬报告，想确认他收到没有」——电话有了正当理由，绕前台不用演戏。成本15-25元/件，50件≈1000元。

## 7.3 漏斗预期（类比推断）

100个精准名单 → 有效触达60-90 → 加上老板微信15-30 → 答应30分钟粗算5-12 → 成交1-3单。**同样精力投熟人圈是这个数字的3-5倍——所以30天内熟人圈优先，冷名单三线从第4周才开始跑。**

## 7.4 合规红线（刑事级，逐条背下）

1. **禁止购买/交换任何含老板手机号的名单**——最高法指导案例194号：获取已公开个人信息改变用途、情节严重构成侵犯公民个人信息罪；单独手机号即属个人信息。
2. 未经同意打个人手机做营销=骚扰电话，12321可举报处罚；**打企业公示座机谈业务风险低得多**，被拒即停。
3. 微信陌生申请每天≤15-20个，不用任何群发外挂；加上后首条消息表明身份来意，被拒即删除信息。
4. 不用爬虫抓平台数据，只用会员正规导出，不转卖不共享。

# 第八部分 · 影响力杀招（快版，全部零预算）

按ROI排序，前三个本月就上：

1. **现场公开诊断（核心表演）**：商会讲台/饭局/粗算电话，一切场合的固定节目=当场算三个数。可控版悬赏嵌进去：「我当场算你三个数，算错一个，今天饭钱我出。」（原"悬赏3000元证伪"降级——独立炒作在专业服务里易显江湖气，嵌入诊断则是自信）。

# 第十部分 · 你没想到（或没排上优先级）的十件事

1. **0号续约是最快的一笔钱，窗口只有这两周。** 所有外部渠道都比不过一个正在付你钱、马上要到期的客户。谈"降频续费"而不是"离场"。
2. **收款硬件先于一切营销**：能开咨询费发票的主体+对公账户+电子合同。企业先付钱的前提是财务上付得出去。B2B里"付款流程走不通"杀死的单子比"不想买"多。
3. **0号合规三查（包就业话术）仍是悬雷**，而且现在双重紧迫：它既是你的续约对象又是你的案例。三查没做完之前：不引用0号为案例、不署名关联。半天的事，本周第一件做。
4. **给自己按新价格体系报价**（第14号已提，再压一遍）：0号续约就是第一单督导月费——你教定价，你的报价单是第一个案例。按友情价续，等于当着客户面否定自己的产品。
5. **银行/政府/国资背景人员一分钱返佣都不能给**（刑事红线有判例）；市场化介绍人返佣10-20%可以给，但必须签协议、对公入账开票——账外现金=商业贿赂。
6. **诊断记录表照建、每场粗算照记**（原10.5字段永不更改）：现金模式跑着，数据资产不能停——警戒线标定=获客过程这个闭环（第14号A门发现）依然成立，而且它是你3年后的护城河。
7. **止损线（研究给出的硬数字）**：熟人圈全力跑**60天卖不出一份诊断**→降价一半再试30天；**90天颗粒无收**→说明现阶段模式对你的人脉不成立，接驻场兼职/临时操盘保底，业余用 Cygnal 模式养内容（一个只回答销售薪酬问题的公众号，是这个细分被验证的最低成本获客机器）。设了止损线，你才敢全力冲。
8. **runway 表本周建**：现金余额 ÷ 月固定支出 = 还能打几个月。每月1号更新。这张表决定你什么时候必须启用第7条。
9. **"十几个观点"先粗后细**（第八部分已展开）：先1天出大纲版立刻投入使用，细致版跟着市场反馈走，不要预先花一周。
10. **每份诊断交付时当场要两个名字**——转介绍不是渠道之一，是你唯一能指数增长的渠道【数据：过半数顾问60%以上业务来自转介】。写进交付SOP最后一步，和"发报告"同级。
