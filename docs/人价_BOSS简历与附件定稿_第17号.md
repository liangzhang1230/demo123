# 第五部分 · 使用纪律（重申+新增）

1. **数字统一令**：案例三行定稿后，在线简历、附件两版、朋友圈、微信话术、商会PPT全部照抄，一字不差。【2亿还是过亿】【盈利还是扭亏】今天定死。
2. **附件分发纪律**：BOSS上只挂求职版；商务版走微信、顺丰包裹、培训机构、商会——两个PDF文件名都叫"张良·销售业绩操盘手"，内容不同，自己存两个文件夹别发混。
3. **站内文字纪律**（第16号3.2重申）：报价、服务名、"咨询/诊断合作"字样、微信号，永不出现在BOSS聊天文字里；商务话题一律电话/见面谈。
4. **"第一"用词**：所有对外材料不用"第一/最/唯一"（商务物料有广告法绝对化用语风险，且不可核验）；用"头部+可当面对数"。
5. **回复率统计**：新版招呼语发满30条记一次回复率，与旧版对比；简历改版后观察一周"被查看→被开聊"比例变化，无提升则回滚单项排查（一次只改一个变量）。
