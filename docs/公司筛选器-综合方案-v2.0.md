### 2B. 企业版根本没有、但个人必需 —— 已落成可计算函数（★重点）

> 这一层是你要我补的东西。每条：**输入 → 函数 → 输出 → 出处**。系数中 🔧 = 我的启发式（可调），✅ = 有实证。

**① 底薪「无责 vs 有责」判定** ✅底060 信号理论
```
输入：底薪额、底薪性质(无责/有责/零底薪)
函数：safeFloor = (性质==无责) ? 底薪 : 0     // 有责底薪在现金流里当 0 算
      redFlag = (性质!=无责)                  // 一票否决候选
输出：安全底（喂给现金流）、红线
意义：真底薪 = 公司拿真金白银为你担险的「有成本可信信号」；
      有责/零底薪 = 把风险全甩给你的廉价信号。这是全表最硬的一条。
```

**② 体感年包折算**（你的 Offer 折算器，形式化）✅底118
```
输入：底薪、发薪月数、画饼年提成、提成兑现率conf、一次性补贴、
      排班(固定0/偶尔0.5/全凭临时1)、远程(不能0/偶尔0.5/常态1)、社保基数(全额0/最低1)、单程通勤分钟、年限
函数：
  salary   = 底薪 × 发薪月数
  commReal = 画饼年提成 × conf
  cash     = salary + commReal + 一次性
  体感年包 = cash − cash×0.20×排班 + cash×0.08×远程 − cash×0.06×社保 − 通勤折现
  通勤折现 = (通勤×2/60×250) × (cash/(250×8))
  N年累计（体感）= Σ_{t<年限} cash×(1+涨幅)^t × (体感/cash)
输出：名义年包 vs 体感年包、N 年累计、逐项对账
意义：offer 上的年包和你到手扣掉隐性成本后的，是两个数。排班临时通知值 20% 工资，居家值 8%（Mas & Pallais 2017 AER，⚠️系数可自调）。
```

**③ 线索归属 / 冷启动折扣** ✅底061 平台红利
```
输入：线索自给率(公司全给1.0 / 一半0.5 / 纯冷启动0.0)
函数：leadFactor = 0.4 + 0.6×自给率          // 🔧 纯冷启动只按 40% 基准成交折算
      → 乘进「期望月成交单数」
输出：折减后期望成交、警示（冷启动=公司拿你的时间做市场测试）
意义：同样提成比例，池子不同收入差一个量级——这一项几乎从不写进 offer。
```

**④ 合同 / 协议时点红线** ✅底122 + 底099 低球术
```
输入：入职前是否给看全部待签协议(是/否)、是否有竞业(有/无/有但无补偿)、提成尾款离职是否发、培训服务期违约金
函数：contractRedline = (!入职前给看) || (竞业无补偿) || (尾款不发)
输出：红线清单 + 筹码警示
意义：约 1/3 的人在「已接受 offer 后」才被拿出协议——机关在时点，等你没筹码那张纸才递过来。
```

**⑤ 棘轮效应（配额年调）→ 多年收入衰减** ✅底004 Chung 2014 MS
```
输入：配额去年是否上调、上调幅度g
函数：第t年有效收入 ≈ 满产收入 × (1 − 衰减)，衰减随 g、t 增大   // 🔧 多干g才平收入
输出：3/5 年收入曲线被「棘轮」压平的可视化
意义：提成比例是给你看的，配额是拿走你钱的。你越拼，明年配额越高。
```

**⑥ 考核维度数 → 短视风险分** ✅底128 Holmström-Milgrom
```
输入：考核指标数量、是否只考核单量
函数：dims>=3 →🟢 ; 1-2能说清 →🟡 ; 只单量 →🔴
输出：「你会变成什么样的人」风险分
意义：只考核当月单量的合同 = 明确通知你「其余的事都不必做」。
```

**⑦ 主管来路 → 带教概率分** ✅底078 彼得原理 + 底011 反馈
```
输入：主管是否销冠提拔、是否仍重背指标、谈下属是「任务/动作」还是「人身评价」
函数：重指标 && 销冠提拔 && 人身评价 →🔴 ; 有带教有案例 →🟢
输出：带教概率分
意义：最会卖的被提拔当主管，反而让下属业绩下滑。
```

**⑧ 平台 / 行业溢价 → 经验增值系数（多年）** ✅底066/107/101
```
输入：行业位置(头部/中部/尾部)、团队一年是扩是缩
函数：expValue = 基准 × 平台系数    // 🔧 尾部平台不只当期少给，还压低你经验的含金量
输出：N 年后「你这段经验值多少钱」的相对系数
意义：弱平台拿走的不只是当期收入，还有你经验的含金量（离开后仍带得走的那部分）。
```

**⑨ 空窗回电率衰减（留）** ✅底067 Kroft 2013
```
输入：预估空窗月数
函数：空窗损失 = 现月收入 × 空窗月数
      衰减警示 = (空窗月 触发阈值)   // 回电概率随空窗下降，大半伤害在头 8 个月
输出：空窗损失金额 + 「越拖越难回」警示
意义：你强调的核心——很多年轻人不懂空窗成本。把它量化砸到脸上。
```

**⑩ 金手铐纠偏（留）** ✅底106 Topel/Altonji
```
输入：用户自估「留下能比外面多拿百分之几」
函数：真实上限 ≈ 11%（而非脑补的 25%+）；对比显示高估幅度
输出：「你可能把『不敢走的理由』脑补大了」
意义：别拿 25% 当不敢走的借口，真实数字大概率低不少。
```

**⑪ 计划谬误爬坡系数** ✅底072 Buehler 1994
```
函数：真实满产月数 = 名义 × 1.5      // 33.9→55.5，明知低估还低估
输出：把爬坡期整体右移，现金流更保守
意义：一家只给你 3 个月证明自己的公司，和你真实需要的时间可能对不上。
```

**⑫ 满意即可门槛（决策哲学）** ✅底126 Simon
```
输入：用户预设一个「过线就去」的门槛分
函数：总分 >= 门槛 → 建议去，停止找「最优」
输出：结构化判决，反内耗
意义：非要挑「最好」那份的人薪水高 20%，却最不满意、最焦虑、最后悔。
```

### 2C. 明确不做 / 降级（诚实边界）

- **不建公司名黑名单 / 评价库**——只算用户自己输入的数（名誉侵权红线）。
- **「练/干」降级**：个人手里没有销冠数据，纯前端蒸馏不出配方。二期做「用你自己漏斗数据自诊断」，不硬编假话术。
- **面试照妖镜**：本质是「老板识别别人」，与「求职者算这家公司」的主线视角错位，且作钩子偏 gimmick、可能起反作用（你的判断对）。**MVP 不做、也不作钩子**；二期若做，降级为「留」里评估未来主管靠不靠谱的选配加测。
- **法律条款**（竞业、违约金）：只做红旗提示，明确「请咨询执业律师」，不给法律意见。

## 4. 极简输入契约（少输入、多功能的关键 = 渐进式披露）

**核心设计：默认只显「秒测」，想更准再逐层展开。个人不嫌麻烦的秘诀就在这。**

| 层 | 输入 | 能出什么 |
|---|---|---|
| **L0 秒测**（默认，30 秒） | 3 个数：城市档、底薪、HR 画饼月收入 ＋ 7 维各点一下 🟢🟡🔴 ＋ 一票否决勾选 | 体检总分 + 一票否决 + 「画饼 vs 底薪」粗判 + 一句话结论 |
| **L1 精算**（想要真数字，+5 个数） | 提成率、提成基数类型、客单价、成交周期档、**实际达标率**（问得到就填）、试用期 | 冷静期望月收入 + 前 6 月现金流 + 达标率折算 |
| **L2 体感**（想扣隐性成本，+滑块） | 排班、远程、社保基数、通勤、发薪月数、年限、涨幅 | 体感年包 + N 年累计 + 逐项对账 |
| **留 · 附加** | 现月收入、空窗月数、金手铐自估 | 空窗损失 + 走的总代价 + 高估纠偏 |

> 铁律：**L0 就能出结论**（钩子在此）；L1/L2 是「想更准」的人自己点开。任何一层数据缺失，显「—」不假装。

## 7. 达标率模型的诚实处理（回答你的疑问）

你问「达标率模型是否准确」——**诚实答案是：别过度建模，优先问出来。** 三档来源，置信度递减，永远可手调：

| 来源 | 怎么来 | 置信度 | 处理 |
|---|---|---|---|
| **A 问出来** | 面试直接问「这岗位上一年实际达标的人占几成」（《体检包》最值钱的一问） | 🟢 高 | 直接用，主推这条 |
| **B 估算** | 定额折算应达回款 ÷（**人均月回款** × 系数），>1.3 判虚高 | 🟡 中 | 给个数，标「估算」 |
| **C 滑块兜底** | 用户凭感觉拉「我信几成」（你 Offer 折算器已有此滑块） | 🟡 低 | 让用户自己担责 |

**关键改进**：达标率不再是黑箱算出来的一个数，而是「优先问真的，问不到就滑块，全程显置信度」。对方答不出达标率、开始讲某个销冠的故事——**那本身就是答案**（🔴）。

## 8. 基准数据（直接用企业版达标月收入表）

**口径 = 达标月收入**（不用人均回款——你说得对，回款没用，月收入才是个人要对标的）。直接搬企业版定价器 `thresholdTTable`，城市 × 档位全齐、无需外部数据。

**达标月收入基准表（元/月，企业版原始值）**

| 城市 | 销售·初级 | 销售·中级 | 销售·高级 | 销售主管 | 预警下限 |
|---|---|---|---|---|---|
| 一线 tier1 | 30,000 | 35,000 | 40,000 | 40,000 | 25,000 |
| 二线 tier2 | 24,000 | 28,000 | 32,000 | 32,000 | 20,000 |
| 三四线 tier34 | 18,000 | 21,000 | 24,000 | 24,000 | 15,000 |

> 对应企业版 `thresholdTTable` 的 idx：初级=effective(1)、中级=efficient(2)、高级=leading(3)、主管=manager(1)；idx0=warning 作**预警下限**（低于此值 = 这岗位在你城市连常规达标线都够不到）。

**档位取舍（已决策）：**
- **保留「销售主管」**：部分人面的是主管/team-lead 岗，保留只是多一个下拉项、零额外复杂度；企业版的「管理跨度/编制人数」逻辑个人版**不需要**，只借「达标月收入」这一行。
